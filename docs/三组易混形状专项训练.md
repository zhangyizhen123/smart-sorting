# 三组易混形状专项训练

范围为圆柱体/圆锥、三棱柱/长方体、正方体/长方体，保留全部九类。目标只针对合成演示，不代表真实相机效果。每个检出的物块始终给出类别，不用拒识提高分数。

## 这次落实的流程

1. 从现有毫米单位 STL 生成场景，同一张图共用像素/毫米比例；不把长方体独立拉伸成正方体。物块按实体面支撑放置，随机转向、灯光和材质。长方体保持现有 40×30×20 mm 定义，不擅自改变类别尺寸。
2. 每类生成 800 个训练目标场景、100 个验证目标场景、320 个测试目标场景；另有配对物块，所以实例数多于场景数。覆盖单物块、多物块、低角度、高角度、小目标、画面边缘、低对比度、接触、局部遮挡十种子集。
3. 遮挡标签按后绘制的物块扣掉不可见区域；不可见、碎裂或带孔的复杂掩膜不属于这版 YOLO 单多边形生成范围，生成阶段就重采样并记录，不根据模型对错筛图。
4. 生成前独立确定各集合的场景种子。生成后保存图像、标签、STL、生成代码与清单哈希；同场景/相同图片不得跨集合，后续评估先核验冻结清单。
5. 主分割模型先训练。复核器只使用训练集合中主模型预测的匹配掩膜裁剪及其真值标签，真值掩膜仅补充训练；验证使用预测掩膜。输入包括灰度、轮廓、边缘和几何比例。
6. 三个二分类头处理三组易混组合；额外的正方体/长方体/三棱柱仲裁头处理长方体同时属于两组的冲突。四个其他类别不参与复核。复核只在验证集证明有效时启用，拿不准则保留主模型类别，不删除该物块。
7. 在验证集选择模型检查点、类别无关去重开关和复核阈值。选择记录固定后才运行测试；测试集不选参数。不提升的复核器保留实验结果，不强行放入演示。

## 99% 的统计口径

先按掩膜 IoU ≥ 0.50 做与类别无关的一对一全局匹配，再判断类别。不能用真实类别挑对自己有利的匹配。

**严格实例得分 = 只有一次检测且类别正确的物块数 ÷（全部真实物块数 + 额外非重复误检数）。**

- 漏检、错分、同一物块检出多个框，都使该物块失败。
- 背景上多报一个物块，作为额外失败计入分母。
- 同时报出普通正确数/真值数，避免把未扣重复检测的旧比例当成严格得分。
- 每类报告 precision、recall、F1，三组双向混淆，以及每个困难子集得分、整图全对比例、漏检/重复/额外误检数量。
- 标准低置信度 mask mAP 单独评估主分割模型；最终流程固定显示阈值下的 AP 单独标注，不能混称。
- 99% 是这个冻结样本集上的实测目标，不是对任意新图的保证；若后续根据测试错误继续改模型，原测试集视为开发基准，最终声称达标前再独立留出新测试批次。

此前口头把混淆矩阵方向解释反了：横轴是真值、纵轴是预测，图中“真长方体→预测正方体”约 30%，52% 是长方体自身的正确分类格，不是长方体→正方体的比例。旧图来自训练验证输出，也不能混称独立测试结果。本轮统一输出“行=真值、列=预测”的明确计数。

## 本机运行与正式配置

依赖：项目现有 `.venv-vision`，再安装 `vision/requirements-focused.txt`。不需要手工标注合成图。

```powershell
.\.venv-vision\Scripts\python.exe -m pip install -r vision\requirements-focused.txt
.\.venv-vision\Scripts\python.exe vision\scripts\make_focused_dataset.py --out dataset\focused_v2 --train-per-class 800 --val-per-class 100 --test-per-class 320 --image-size 640
.\.venv-vision\Scripts\python.exe vision\scripts\run_focused_training.py --dataset dataset\focused_v2 --profile cpu_pilot --out runs\segment\focused_v2_cpu
```

生成器拒绝覆盖非空目录。已有数据可用 `make_focused_dataset.py --out dataset/focused_v2 --verify` 检查。训练中断后可用相同运行命令继续；配置变化必须换输出目录。

- **CPU 试运行**：沿用首版 YOLO11n-seg 权重，320 输入、20 轮；从每类各难度等比例抽取 60 个训练场景，共 540 张。验证和测试仍使用完整冻结集合。这个试运行验证工程和初步收益，不能写成已经完成正式配置。
- **正式配置**：YOLO11s-seg、640 输入、150 轮、全部 7,200 张训练图；在已有环境上使用 `--profile full --out runs/segment/focused_v2_full`。有 CUDA 时用 GPU，否则会在 CPU 上运行很久。配置统一保存在 `vision/configs/focused_training.json`。
- 不自动租用付费 GPU，不擅自安装或更换显卡驱动。YOLO11m-seg 仍为后续候选，不是本轮必跑项。

每次运行产生 `status.json`、训练日志、冻结数据哈希、验证选择记录、三组复核结果、最终指标、错误样图、混淆矩阵和可加载的模型包。失败会记录错误，不能把启动成功当作训练完成。

## 你怎样使用

训练、标注、评估这些工作由我处理，这一步你不用准备图片或手工标注。训练期间电脑需要保持开机、不要进入睡眠；如果中断，已保存的训练状态可以续跑。

完成验收并归档后，双击项目根目录的 **演示专项模型.cmd**，等待页面显示模型就绪，选择本机图片，再点击“识别形状”。启动窗口保持打开。原来的 **演示模型.cmd** 继续作为首版对照。

专项页面会单独显示该模型实际的严格实例得分，以及是否达到 99%；预置的十二张样例及上方 mAP 明确标为首版结果。复核改变类别时，显示的基础检测置信度不能解释成新类别的校准概率。
