更新：2026-11-08。项目当前重心是训练视觉模型。本文汇总流程、数据、结果和下一步；任务状态以 [任务跟踪表](任务跟踪表.md) 为准，整体流程见训练流程页面（D-36/D-39 等任务的证据在 `runs/task_audit/`）。

## 关键决定（用户，2026-11-08）

- 46 张手机实拍与现有 STL 合成数据有缺陷：**保留只作参考，不用于训练和评估**。新数据只来自最终固定相机。

- **两条线并行**：纯实拍线（主文件夹会话，分支 `pilot-labeling-smoke-training`）与仿真线（独立会话与 worktree，分支 `claude/sim-line-546d65`，见 D-35）。仿真线不改任务表，由纯实拍线合并后统一更新。

## 已验证的流程

```
MaixCAM 2 拍照（锁定曝光，按回车拍）→ dataset/raw_sessions/<会话>/ + <会话>.manifest.json
→ session_labeling.py draft（V5 初判 + MobileSAM 轮廓）→ review（本机审核页）→ export（冻结格式 + data.yaml）
→ 传到 GPU 训练机 → run_experiment.py run（训练、冻结检查点、评估、报告）→ 报告取回 runs/experiments/
```

| 环节 | 工具与要点 |
| --- | --- |
| 拍照 | 相机上 `/root/sorting/tools/session_capture.py SESSION COUNT 9994 2688`，经 `ssh -t` 在本机终端按回车拍；640x480，曝光 9994、增益 2688 锁定；屏幕归系统启动器，拍照程序运行时不要在相机屏幕上打开相机应用（会冲突重启） |
| 入库 | 拍完 `scp` 回 `dataset/raw_sessions/<会话>/`，逐文件比对 MD5，生成 `<会话>.manifest.json`（SHA-256、相机参数、`group`） |
| 草稿 | `python vision/scripts/session_labeling.py draft --session <会话>`；V5 阈值 0.15；MobileSAM 权重 `dataset/tools/mobile_sam.pt`（SHA-256 `6dbb9052…6c2f`）；SAM 轮廓落在提示框内（≥90%，面积 ≥ 框的 15%）即为默认 |
| 审核 | `... review --session <会话>` 打开 http://127.0.0.1:8770/ ；逐个改形状或标“不是物块”，“添加漏标物块”拖框，“重画轮廓”“手动描边”修轮廓；每张保存即落盘；保存时若两个确认物块的轮廓重叠超过较小者的 5%，页面提示并停在本张；`... status --session <会话>` 也会列出 `overlap_problems` |
| 导出 | `... export --sessions <会话...> --split train --out dataset/suites/<名称>`；只导出人工确认的物块，带会话分组；有超过 5% 的轮廓重叠就整批拒绝、不写任何文件（`--max-overlap` 可调，记入 `freeze.json`）；传到训练机后需把 `data.yaml` 的 `path` 改成训练机路径（不影响冻结哈希） |
| 训练/评估 | `python vision/scripts/run_experiment.py run --config vision/configs/experiments/<配置>.json`；规则见 [统一实验入口说明](统一实验入口说明.md)：训练集与评估集有同图或共用独立会话会被拒绝，封存测试只能用一次 |

## 数据与结果

**pilot_s01**（最终固定相机、当前大托盘 `tray_v1`，40 张）：人工确认 93 个物块（圆柱 8、正方体 17、长方体 7、三棱柱 13、五棱柱 9、六棱柱 8、圆锥 9、四面体 15、球 7），17 个手动补标，38 个标为非物块，4 张空盘。当前版本 `dataset/suites/pilot_s01_v2`（清单 SHA-256 `13a81002…31d6`）：修正了 v1 的两处轮廓（26 号五棱柱圈进了后面的长方体，14 号正方体圈进了后面圆锥的尖），其余与 v1 相同；v1（`4036608b…a3a2`）保留作记录。25、26 号左侧大绿棱柱经用户确认是两块不同积木（六棱柱、五棱柱），标签无误。证据 `runs/task_audit/2026-11-08_pilot_s01_v2_label_fix.json`。该批不能作选型或封存测试（旧托盘）。

审核经验：SAM 轮廓偶尔会把紧贴在后面的积木一起圈进去；修正时容易把原物块保留成确认状态，又新增一个，造成同一块算两次。现在审核页、`status` 和导出都会检查轮廓重叠：正常相邻只是边缘接触（pilot_s01 最多 1.2%），出错时在 99% 以上，门槛定为 5%。

**训练前基线**（`runs/experiments/pilot_s01_baseline_v2`，在 v2 上重跑，与 v1 结果相同；这批照片此前未参与任何训练，只作诊断）：

| 模型 | 严格实例得分 | 漏检 | 额外误报 | 空盘报警 |
| --- | ---: | ---: | ---: | ---: |
| V5（合成测试 86.01%） | 16.1% | 14 | 25 | 50% |
| 首版 | 9.5% | 30 | 75 | 100% |

V5 逐类：圆柱 8/8、圆锥 6/9、球 3/7、长方体 1/7、四面体 1/15，正方体 0/17、三棱柱 0/13、五棱柱 0/9、六棱柱 0/8。草稿阶段 V5 形状初判 18/78 正确。额外误报含画面里的遥控器。

**冒烟训练**（`runs/experiments/pilot_s01_smoke_train_v1` 与 `_fit_v1`）：在训练机 RTX 5060 笔记本版上从首版权重训练 5 轮（约 50 秒），检查点哈希已冻结；训练拟合（自身 40 张）严格得分 11.0%，四面体 13/15、三棱柱 8/13，其余未学会。只证明链路可用，不代表效果（用的是含两处错误轮廓的 v1，不重跑）。

## 训练机与相机

- GPU 训练机：借用的 RTX 5060 笔记本版（8 GB，约 6 GB 可用），Python 3.13 + `vision/requirements-gpu-cu132.txt`（torch 2.15.0+cu132，torchvision 0.29.1+cu132）；工作目录在 D 盘专用文件夹；只在与机主约定的时段训练；**SSH 断开会结束远程进程**，长时间训练需本机保持连接或由机主建计划任务（D-38）。
- 相机：MaixCAM 2，MaixPy 4.12.5，系统镜像 2026-05-29，可用内存约 446 MB；系统自带通信协议默认占用 UART4（`/dev/ttyS4`），接 STM32 前需处理（U-04）。
