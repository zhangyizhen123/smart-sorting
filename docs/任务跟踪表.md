## 更新方法

在项目根目录执行；完成任务时必须写实际证据，不以“准备完成”或仅修改状态代替验收。

```powershell
python scripts/update_task_tracker.py update 任务编号 --status 已完成 --evidence "产物路径与验证结果" --note "本次完成说明"
python scripts/update_task_tracker.py render
python scripts/update_task_tracker.py check
```

CSV 直接编辑后执行 render。程序 update 会同步 CSV、Markdown 和 Excel，并追加更新记录。Excel 是生成的阅读版；若直接修改了工作簿，请先合并回维护数据再重新生成。
