# 给老师展示这版模型

现在已有一版九类形状实例分割模型：既输出物块属于哪种形状，也输出它在图像里的轮廓。展示使用合成测试图片，目前不需要托盘或相机。

## 最省事的打开方式

1. 打开项目文件夹 `E:\智能分拣`。
2. 进入 `docs\stl_shape_v1_demo`，双击 **index.html**，用 Edge 或 Chrome 打开即可。不需要联网，也不需要安装 Python。
3. 点击左侧的形状名称切换样例。左边是输入图像，右边是模型输出；图中的编号对应下方的中文类别和置信度。
4. 勾选“显示参考轮廓”，可以对照自动标注与模型轮廓。切换“显示预测轮廓”“显示预测框”查看不同结果。

该页面显示已经运行并保存的模型结果。只把 **index.html** 复制到另一台电脑，也能完整展示；图片和结果都在文件内。

## 现场重新运行一次模型

在这台已配置环境的电脑上，双击项目根目录 **演示模型.cmd**。程序会读取归档权重，重新预测附带的 12 张图片，并自动打开更新后的页面。首次启动可能需要等几十秒。看到中文演示页面后即可开始讲解。

重新运行用到的图片已随项目保存，不需要生成全部训练数据，不会重新训练模型，也不会读取摄像头。若另一台电脑要重新推理，先按 [STL 合成训练步骤](../vision/STL合成训练.md) 安装环境。

供维护者使用的等效命令（在项目根目录运行）：

```powershell
.\.venv-vision\Scripts\python.exe vision\scripts\predict_stl_demo.py
```

加 `--no-open` 可只生成结果而不打开浏览器。静态拼图可用 `python vision\scripts\make_stl_prediction_montage.py` 从同一份预测重新生成。

## 建议按这个顺序讲，约三分钟

1. **先说做了什么。**“还没有托盘实物时，我们用九个 STL 自动生成训练图片和轮廓标签，训练了第一版模型。”
2. **展示圆柱、球体和多物块。**点击对应样例，指出输入图像、预测轮廓和类别，说明一张图可以处理多个物块。
3. **主动展示当前短板。**点击正方体、长方体，对照标注和预测列表，说明模型会误识别或对同一个物块给出多个类别。页面保留了这些原始预测。
4. **说明指标和下一步。**“独立合成测试集是 108 张、273 个物块，mask mAP50 约 0.915，严格一些的 mAP50–95 约 0.872。这不是实物准确率。后面要用固定好的最终相机采集真实图片，人工复核标签，再训练和验证。”

## 能交给老师的文件

- 直接展示：[中文演示页面](stl_shape_v1_demo/index.html)。单文件可离线复制。
- 书面说明：[首版训练结果](视觉训练结果_STL首版.md)。包含九类指标、局限和复现入口。
- 静态图片：[预测拼图](视觉训练首版预测拼图.jpg)。图上只放编号，中文预测在下方。
- 模型文件：`models/trained/stl_shape_v1/best.pt`。

这轮不需要你拍照或手工标注，也没有需要你先交付的材料。如果要展示，只需要打开页面；要现场证明模型能运行，就双击“演示模型.cmd”。实物阶段的采集与测量另行安排。
