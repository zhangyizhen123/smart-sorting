# 给老师展示这版模型

现在已有一版九类形状实例分割模型：既输出物块属于哪种形状，也输出它在图像里的轮廓。可以查看预置样例，也可以导入你自己的图片进行识别；不需要接相机。

另有三组专项**试验版**：双击根目录 `演示专项模型.cmd`，后续选图和识别操作相同。它在新冻结合成测试上的严格得分为93.62%，尚未达到99%；旧测试集发生退化，不能说它已经全面优于首版。详见[专项结果与局限](视觉训练结果_三组专项.md)。页面上方的108张测试与mAP卡片仍是首版对照，专项分数在下方单独显示。

## 导入自己的图片并识别

1. 打开 `E:\智能分拣`，双击 **演示模型.cmd**。
2. 等待浏览器自动打开。看到右上角“本机模型已就绪 · 可导入图片”后就能使用。启动时出现的窗口要保持打开，它负责运行模型。
3. 在“导入自己的图片”区域点击 **选择文件**，从电脑里选一张图片。支持 JPG、PNG、WebP、BMP，单张不超过 20 MB。
4. 点击 **识别形状**。左边显示输入图片，右边显示模型找到的物块轮廓；图上编号对应下面的中文形状名称和置信度。一张图中可以有多个物块。
5. 想换图，就再次选择文件并点击识别；想查看示例，就点左侧的形状按钮；点“查看导入图片”可以回到刚才的结果。

“最低置信度”默认是 0.25。往右调会减少不确定的预测，往左调会保留更多候选，但也可能增加误检。调整后要重新点击“识别形状”。没有检出时页面会提示，不会沿用上一张图片的结果。

图片只在本机处理，不上传到外部网站，也不会自动加入训练集或保存到项目。横图、竖图按原比例显示；程序会修正手机照片的方向，并将过大的图片等比例缩小后识别。

使用结束后，关闭启动窗口即可停止模型服务。如果误关了窗口，重新双击 `演示模型.cmd`，使用新打开的页面。

**你需要准备的东西只有一张保存在电脑上的图片，不用画框或标注，也不用先把图片发给我。** 模型只学过九类合成形状，导入实物照片是初步尝试；未知物体也可能被误判成九类之一，请对照原图检查。

## 只查看已经做好的样例

1. 打开项目文件夹 `E:\智能分拣`。
2. 进入 `docs\stl_shape_v1_demo`，双击 **index.html**，用 Edge 或 Chrome 打开即可。不需要联网，也不需要安装 Python。
3. 点击左侧的形状名称切换样例。左边是输入图像，右边是模型输出；图中的编号对应下方的中文类别和置信度。
4. 勾选“显示参考轮廓”，可以对照自动标注与模型轮廓。切换“显示预测轮廓”“显示预测框”查看不同结果。

该页面显示已经运行并保存的模型结果。只把 **index.html** 复制到另一台电脑，也能完整展示；图片和结果都在文件内。

直接打开 HTML 文件时，“导入自己的图片”区域会提示通过 `演示模型.cmd` 启动。只有本机模型启动后，才能识别新图片。

## 给维护者的启动与更新命令

双击入口现在启动本机识别服务并打开页面。预置的 12 张样例仍使用已保存结果；导入新图片后，每次点击识别都会实际调用模型。若另一台电脑要识别新图片，先按 [STL 合成训练步骤](../vision/STL合成训练.md) 安装环境。

在项目根目录启动服务：

```powershell
.\.venv-vision\Scripts\python.exe vision\scripts\serve_stl_demo.py
```

加 `--no-open` 只启动服务，不自动打开浏览器。默认使用本机端口 8765，被占用时自动换空闲端口；地址会打印在启动窗口。停止服务按 `Ctrl+C`。

如果需要重新计算预置的 12 张图，运行 `.\.venv-vision\Scripts\python.exe vision\scripts\predict_stl_demo.py --no-open`。只更新页面模板可用 `--render-only --no-open`；静态拼图仍用 `python vision\scripts\make_stl_prediction_montage.py` 生成。

## 建议按这个顺序讲，约三分钟

1. **先说做了什么。**“还没有托盘实物时，我们用九个 STL 自动生成训练图片和轮廓标签，训练了第一版模型。”
2. **展示圆柱、球体和多物块。**点击对应样例，指出输入图像、预测轮廓和类别，说明一张图可以处理多个物块。
3. **主动展示当前短板。**点击正方体、长方体，对照标注和预测列表，说明模型会误识别或对同一个物块给出多个类别。页面保留了这些原始预测。
4. **说明指标和下一步。**“独立合成测试集是 108 张、273 个物块，mask mAP50 约 0.915，严格一些的 mAP50–95 约 0.872。这不是实物准确率。后面要用固定好的最终相机采集真实图片，人工复核标签，再训练和验证。”
5. **现场试自己的图片。**选择一张准备好的图片，点击“识别形状”，解释轮廓、类别和置信度。导入图不参与页面上方的合成测试集指标计算。
