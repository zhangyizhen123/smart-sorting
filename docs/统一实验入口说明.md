# 统一实验入口说明（D-36）

`vision/scripts/run_experiment.py` 用一份 JSON 配置描述一轮视觉实验：冻结数据 → 可选训练 → 标准评估 → 报告。以后新实验写新配置即可，不再每轮新增 `run_*`、`register_*`、`release_*` 脚本。历史脚本保留不动。

## 两条命令

```powershell
# 把一次新拍摄会话（图片 + YOLO 分割标签）冻结为评估集；空盘用空的 .txt 标签
.\.venv-vision\Scripts\python.exe vision/scripts/run_experiment.py freeze-suite --images 新会话图片目录 --labels 标签目录 --out dataset/real_dev_session_20261120 --split val --group session_20261120

# 按配置运行一轮实验
.\.venv-vision\Scripts\python.exe vision/scripts/run_experiment.py run --config vision/configs/experiments/实验名.json
```

## 配置要点

| 字段 | 作用 |
| --- | --- |
| `suites` | 评估集：冻结目录（`manifest.jsonl` 和 `freeze.json`），`role` 为 `selection`（选型）、`regression`（回归）、`diagnostic`（诊断）或 `sealed_test`（封存测试）；`group_fields` 按会话、场景等分组；`independent: true` 表示与训练数据的组也不能重叠 |
| `candidates` | 候选：`model` + `settings`（检查点）、`pipeline`（任何版本的发布包，V5 直接走演示同一运行时），或 `trained: best/last`（本轮训练产物） |
| `train` | 可选；经 `train_seg.py` 训练，必须给出训练数据 `manifest` 用于泄漏检查 |
| `selection` | 只能使用 `role` 为 `selection` 的评估集排序 |
| `comparisons` | 严格得分差的配对 bootstrap 区间；`unit` 可以是 `image` 或分组字段（如按会话整体重抽） |
| `gates` | 门槛：`greater`（超过基线加容差）或 `non_inferior`（不比基线差超过容差），可用区间下界判定；具体数值待 R-13 确认，未确认前报告标为“草案” |

示例：[stl_demo_reproduction_v2.json](../vision/configs/experiments/stl_demo_reproduction_v2.json)。v1 是换行修复前的记录，按"代码变化后不续跑"的规则只作历史保留。

## 自动执行的规则

- 每个评估集都核对 manifest 哈希及每张图、每个标签的哈希；训练数据与任何评估集有相同图片即拒绝运行，与 `independent` 评估集共用分组也拒绝。
- 同一输出目录只代表一轮实验：配置、评估集或评分代码变化后拒绝续跑，需换新名字。中断后重跑会复用逐图缓存（`cache/` 不入库）。
- 换行不算改动：配置按解析后的内容计算哈希，Git 在 Windows 上检出为 CRLF、重新缩进或调整键顺序都不影响续跑；本入口和剪贴生成器写出的清单、标签、冻结文件和报告一律用 LF，同一份数据在 Windows 和 Linux 上得到相同哈希。图片和权重等二进制文件仍按原始字节校验。
- 训练完成后冻结 best/last 哈希；检查点被改动即拒绝。已有未完成的训练目录不会被覆盖。
- 封存测试必须在 `selection_closed: true` 后才能评估，不能参与选型；`runs/experiments/sealed_ledger.json` 记录首次使用，另一轮实验再用同一封存集会被拒绝。
- 报告 `report.json` / `report.md` 给出严格实例得分、漏检、重复、额外误报、每图误报、空图报警率、边界 IoU（未匹配记零）、逐类与混淆矩阵、分组结果、配对区间和门槛结果。入口从不更换默认模型。

## 已做的端到端核对

用仓库自带的 12 张首版演示样例冻结评估集后运行示例配置：首版 12 张图、23 条预测的类别顺序与 `docs/stl_shape_v1_demo/predictions.json` 归档完全一致，置信度差不超过 1e-6（归档保留 6 位小数）；V5 组合在 2 线程和 7 线程下的类别都与演示服务实际输出一致。换行修复后用 v2 重跑，结果相同；把 v2 配置改成 CRLF 后续跑被正常接受，逐图缓存一条未重算。报告见 `runs/experiments/stl_demo_reproduction_v2/report.md`。

重建示例评估集的命令（清单哈希应为 `b042afa5…1c26`）：

```powershell
.\.venv-vision\Scripts\python.exe vision/scripts/run_experiment.py freeze-suite --images docs/stl_shape_v1_demo/samples --labels docs/stl_shape_v1_demo/samples --out dataset/stl_demo_samples_suite_v2 --split test --group stl_demo_samples
```

这 12 张是当初为首版挑选的旧风格合成样例，样本很小，只用于核对工具：首版严格得分 77.78%，V5 为 61.11%（7 处错类，含四面体两处），差值区间 [-42.1, +6.7] 个点，不构成任何模型优劣结论。
