# 持续优化验收约定

记录日期：2026-11-01。用户授权持续优化并更新演示，随后明确“Pareto最优”的实际要求为：在更大的数据集上，识别效果、误报控制、轮廓精度三项均超过旧模型。以此为验收要求，不用速度换质量。当前目标为active；没有授权付费云服务。

## 比较基线与数据

- 首版按原演示320输入、置信度0.25、IoU0.7及原NMS设置；专项版按归档pipeline的320输入、类别无关NMS及分类复核器。不能用错误输入尺寸或漏掉复核器削弱旧模型。
- 先扩大开发验证：108张旧风格、900张专项风格，并增加100张确定没有分拣物块的程序合成背景。冻结训练/验证划分及哈希，测试集不参与选型。
- 已批准46张实拍仍全部属于训练组；重复采样不是新增样本，也不是独立实拍验收。实拍独立验证/测试目前缺失，不能宣称真实场景泛化或99%。
- 候选选定后另用未参与调参的新场景合成测试作最终对照；固定相机实拍验收仍需真实新增数据，合成数据不能代替它。

## 三项共同门槛

1. 识别：一对一实例严格得分超过旧模型，逐类和旧/专项风格分别检查，不能以一个领域提升掩盖另一个明显退步。
2. 误报：相同图片、固定阈值下，报告每图额外误报和空场景误报率，须低于旧模型；同时检查漏检，不能只提高阈值把所有预测删掉。
3. 轮廓：报告掩膜IoU、边界IoU与中心误差。共同匹配物块的边界质量及未匹配按零计的总体边界表现均需改善，避免仅用检测数变化解释轮廓提升。

使用同一套数据对所有模型比较。数据规模、样本来源、训练污染状态和置信区间明确报告。达标前保留原默认模型；新诊断页可先展示真实对照与失败样例。

## 首轮优化实验

已完成976图次轮廓实验：单纯规整降低了顶点数量，但没有整体提高边界指标；直接提高输入到960明显退步。因此保留原始轮廓默认显示，停止把这两条路径视为模型质量升级。

下一步补充完整旧风格训练、按类别/场景均衡抽取专项训练、保留实拍及空盘负样本，进行较低学习率的本机CPU回放微调。首轮冻结前10层，6轮、640输入、batch4、双线程、保存每轮权重；这是可追溯实验，不是达标承诺。后续参数选择依据扩大后的验证集和实际错误分析，不查看最终新测试结果调参。

由助手负责数据、脚本、训练、评估和演示更新。不中断以等待不必要的确认；遇到真实独立实拍材料缺失时明确记录，不伪造材料或成果。

## 最终测试前关闭本轮选型

如果一个完整组合已通过全部开发门槛，可以冻结这个已完成的组合进入最终测试，不必等待其他探索训练跑完预定轮数。此时保存候选、全部处理步骤与代码哈希、旧模型身份及开发比较快照，并明确关闭本轮选型。尚在运行的训练及随后生成的候选不能替换这一轮已锁定的测试对象。

该规则只用于关闭探索、固定测试对象，不降低识别、误报、轮廓、分风格保护及置信区间要求。最终测试使用完整推理链；失败不得用同一组已曝光测试继续调参并重新宣称独立验收。

## 首轮未通过后的第二轮

首轮总体三项改善，但专项风格保护失败，不发布。原 2900 张最终测试保留原身份和全部证据，不纳入下一轮参数筛选。新增 2900 张开发场景，与原 1108 张合成开发图共同选择候选，46 张实拍仍只作为训练拟合检查。要求原开发集和新开发集分别通过共同门槛；在合格候选中优先选择最弱风格提升余量较大的组合。

第二轮提前固定全新 5800 张最终场景的生成配置（1800 旧风格、3600 专项风格、400 空背景）。可提前生成，但候选锁定和原生运行核对通过前不运行预测，也不读取其逐图结果选型。第二轮使用本轮配对、分层 bootstrap 和更严格的本轮联合区间（家族 alpha 0.025），不宣称跨所有历史尝试的全局最优或整体置信度。
