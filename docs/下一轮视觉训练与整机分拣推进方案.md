# 下一轮视觉训练与整机分拣推进方案

保存日期：2026-11-01。本文保存已讨论的总体方案；**保存方案不代表已经训练、部署或实机验收**。

## 目标与当前基线

固定斜视 MaixCAM 2 拍整盘 → 九类形状分割、十色判断、抓取坐标 → 至少3帧一致 → 六种形状颜色组合动态映射六盒 → STM32每次执行一个目标 → 确认正确盒位和光电投放 → 计数并重新拍照。

当前专项模型在新合成测试严格得分93.62%，旧测试72.16%降到65.69%。下一轮先修复跨场景退化，再加入实拍，不以mAP代替逐件准确率。首版、专项版继续保留。

用户已有相机与部分物块，尚不能据此认为最终安装、托盘和九形状十颜色齐备。云资源总额度不超过100元（含算力和存储），重拍仍认不准就暂停。没有承诺100元内一定达到99%。

## 阶段一：部署小样和真实采集

先用已有小模型验证目标MaixCAM 2的软件版本、手动转换、加载、分割后处理与同图坐标对齐，通过后才安排正式付费训练。官方资料需按实际SDK版本复核，不能由网页转换器或电脑ONNX成功推断板上成功。

你需要做：提供相机版本、现有物块形状/颜色/数量清单；把相机固定在接近最终安装的位置；没有托盘时按已核对CAD内部尺寸用胶带围出拍摄范围，用尺子拍参考图。先交20—30张原始照片及安装全景照，我检查后再发完整拍摄清单。照片不用聊天软件压缩，不把手持手机照片当最终固定相机的验收数据。

正式开发采集目标：每种已有形状60张单物块图（分两次采集，40训练/20验证）；120张多物块图；20组逐件取走序列；30张空托盘/背景图。覆盖中央、四边、朝向、稳定姿态、接触和光照变化。按拍摄会话、场景和物块分组，近邻帧不得跨训练验证；最终测试另日重新摆放并封存。

我负责筛图、重复检查、预标注、叠加核对页、格式转换；你确认真实形状/颜色、漏标物块和错误轮廓。验证和测试逐张复核，自动预测不能直接作为真值。

## 阶段二：混合训练与预算

本轮主线YOLO11n-seg，640输入，batch 8（显存不足降4，保持640），其他参数及随机种子在开训前冻结。短实验：首版、专项版各最多15轮，同一分层子集；只用验证集比较并选起点。正式合成最多80轮，patience 15，旧风格40%、专项与整盘60%。实拍微调最多30轮，patience 8，旧风格30%、专项整盘40%、真实30%。比例指采样比例，缺失实物类别保留合成覆盖。

重点：圆柱/圆锥的尖端与横放；三棱柱/长方体的端面和遮挡；正方体/长方体的尺寸比例和透视。九类整体回归也必须检查，尤其四面体、五/六棱柱和小目标。增加实际透视的6种组合、12件整盘场景及逐件取走序列，形状和颜色独立随机。

验证选择先要求旧、新风格均不退步，再比较实拍。没有候选通过则报告失败，不默认升级。复核器只有验证存在增益且板上成本允许才保留。

预算封顶：环境/测速10元，合成训练45元，实拍微调30元，存储/重跑预留15元。先本地备好数据，购买前查实际计费项，短跑估计时长，设置限时、保存、停止并核对剩余收费资源；不足即保存退出，不自动充值。账号登录付款由用户本人操作，不索取密码。本轮仅归档和诊断，不创建或消费云资源。

## 阶段三：分拣业务与接口

形状由分割模型输出；颜色采用实际相机、光照、材料采样建立Lab配置；抓取坐标要验证中央、四边、四角及不同高度姿态。四点平面标定不能自动解决物块高度视差。位置容差以实际夹爪测量为准，初始工程门槛为定位误差不超过可容忍偏差的一半。

后续实现默认：至少3帧一致；首次稳定识别分配六盒，同帧并列按托盘Y→X坐标升序；盒号由机械回零位置核实。复核窗口3秒，仍不可靠则暂停并保存原因图。调试人工处理后恢复需重新扫描，保留本轮映射与计数；无检测不能直接当空盘，结合独立占用检查。比赛人工处理及15秒无动作等条款必须核验适用规则，不能把调试恢复当比赛运行流程。

保持UART v1目标字段与18字节payload，后续增加视觉复核/暂停/恢复/结束状态及日志。只有正确盒位和有效光电投放共同确认后才计数。物理安装、接线、摆放和抓放观察由用户/队友完成；脚本、评估、适配和文档由助手负责。

## 阶段四：验收与更换版本

- 已查看的测试用于开发回归；另留新旧风格独立批次，与两个历史模型同集对比。
- 识别严格得分目标≥99%；漏检、错分、重复和额外误检均计入，逐类报告。
- 最终实拍至少1000个已核验实例，每个纳入验收的形状至少100个，报告样本量、覆盖范围和置信区间。部分实物不能支持全九类验收声明。
- 板上与电脑同图对比，量化得分下降不超过1个百分点，报告颜色、坐标、P95延迟、内存和温度。
- 整机先10轮预验收；实物齐备后100轮、每轮12件6类组合，目标零错盒、逐件成功≥99%，另报整轮全成功率和节拍。
- 暂停、拒识和未完成仍计入分母。识别99%不等于整机99%。验收通过才替换默认模型。
