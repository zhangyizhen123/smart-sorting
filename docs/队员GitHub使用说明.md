# 队员 GitHub 使用说明

项目仓库：<https://github.com/zhangyizhen123/smart-sorting>

队员只需要使用浏览器，不需要学习命令行。上传资料前，请先接受仓库协作者邀请，并使用自己的 GitHub 账号登录。不要共用账号或密码。

## 查看项目进度

打开仓库后，先阅读：

- `README.md`
- `docs/项目总结.md`
- `docs/任务跟踪表.md`
- `docs/任务跟踪表.xlsx`

## 下载资料

- 下载单个文件：打开文件后点击下载或查看原始文件。
- 下载整个项目：点击绿色 `Code` 按钮，再选择 `Download ZIP`。

## 上传资料

1. 进入资料应该放置的文件夹。
2. 点击 `Add file` → `Upload files`。
3. 拖入文件，或点击选择文件。
4. 在提交说明中写清楚本次上传内容。
5. 点击 `Commit changes` 完成上传。

提交说明示例：

```text
上传：相机安装照片和标定数据
上传人：张三
日期：2026-10-31
```

如果不确定资料放在哪里，可以先放入 `shared/` 文件夹。建议文件名使用：

```text
YYYYMMDD_姓名_资料内容.扩展名
```

例如：

```text
20261031_张三_托盘标定照片.zip
20261031_李四_相机安装尺寸.xlsx
```

## 进度反馈

不要直接修改 `docs/任务跟踪表.xlsx`。这个工作簿由项目负责人维护，直接修改可能导致表格和维护数据不同步。

有进展时，请在仓库的 `Issues` 中新建一条记录，写清楚：

- 完成了什么；
- 证据或资料在哪个文件；
- 还存在什么问题；
- 下一步准备做什么。

Issue 标题示例：`进度：完成托盘四角标定`。

## 上传规则

- 不要直接删除或重命名别人已有的文件。
- 不要上传密码、Token、身份证、私人聊天记录等敏感信息。
- 单个文件不要超过 100 MB。
- 视频、大数据集、训练权重等大文件不要直接上传 GitHub；先放网盘，再在仓库上传说明和链接。
- 上传前先检查文件名、路径和提交说明。
