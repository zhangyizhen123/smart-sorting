# 轮廓规整与分辨率对照说明

记录日期：2026-11-01。按用户已确认的方案执行。本阶段不新增训练、不使用云资源、不替换默认部署模型。

## 处理范围

采用首版原权重与本轮实拍混合微调权重，各以640、960输入，覆盖46张参与过训练的实拍和198张合成验证图，共976图次。实拍结果不是独立准确率。每次预测保存原始二值掩膜与规整后掩膜，PNG及逐图记录均有哈希。

几何规整完全不使用预测类别来强行指定边数或圆形。以原图坐标对每个闭合轮廓独立使用`approxPolyDP`，允许偏移为物块检测掩膜框对角线的0.25%，限制0.5—2像素。原始/规整掩膜IoU至少98%，面积变化不超过2%，中心偏移不超过允许误差；连通区域和孔洞数保持不变，不新增与邻块的重叠。保护条件不满足就保留原始轮廓，记录回退原因。细小或退化轮廓不强行处理，不补画遮挡。

原始掩膜、训练标签、模型类别和置信度不变。规整只用于诊断显示，不下发抓取点，也不将新轮廓写回训练集。

## 评价口径

- 严格得分沿用已有类别无关、一对一最大匹配，同时处罚漏检、错类、重复及额外误报；分别采用50%、75%、90%的掩膜IoU匹配门槛。
- 边界IoU使用内侧边界带，宽度为图像对角线的0.5%，取整且至少1像素；图像边缘补零后腐蚀。匹配实例的边界均值与匹配数/未匹配数一同报告，并另存未匹配实例按零计分的边界均值。
- 中心使用掩膜像素质心，报告匹配实例的像素误差、P95及对图像对角线的归一化误差；未标定前不换算毫米，更不等同真实抓取误差。
- 原始与规整分别评价；另使用原始匹配关系计算同一物块的边界指标变化，避免匹配集合变化制造改善。
- 空盘、单白块、多物块和已确认遮挡示例单列。遮挡组只含`IMG_20261102_002244`，属于多物块组，不能将子组相加扩大样本量。

## 复现与界面

配置：`vision/configs/contour_audit_v1.json`。输入和实现哈希冻结在输出目录；已有逐图记录及PNG经过哈希校验后可续跑。

```powershell
.\.venv-vision\Scripts\python.exe -m unittest discover -s vision/tests -p test_contour_quality.py -v
.\.venv-vision\Scripts\python.exe -m unittest discover -s vision/tests -p test_contour_audit.py -v
.\.venv-vision\Scripts\python.exe vision/scripts/run_contour_audit.py
.\.venv-vision\Scripts\python.exe vision/scripts/report_contour_audit.py
python vision/tests/check_contour_audit.py
python scripts/update_task_tracker.py check
```

完成后双击项目根目录`查看轮廓诊断.cmd`。页面默认显示原始轮廓、关闭检测框，可切换规整、640/960与子组，点图片或预测列表放大。原有静态训练前后对照保留，新增新版入口。
